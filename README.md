# AI-Powered-content-summarizer-and-Quiz-Generator-
# 🥷 AI

NovaAI Stealth Studio is a high-performance, local Django web application designed to instantly parse raw text blocks or uploaded document formats (`.pdf`, `.txt`) into smart executive summaries and gamified interactive quiz checkpoints. 

Built using a high-contrast **Black & Red**, the platform operates completely client-side and via native python string mechanics without relying on external cloud APIs.

---

## ⚡ Key Features

* **Dual-Input Pipeline:** Process content via direct copy-paste buffer streams or drop local files (`.pdf` / `.txt`) straight into the engine.
* **Extractive Abstract Summarization:** Native Python backend parsing architecture that extracts core thesis elements without remote dependencies.
* **Threat Evaluation Difficulty Levels:** Generate custom structural evaluations tailored to your choice of difficulty: **Low Intel (Easy)**, **Mid Level (Medium)**, or **High Tier (Hard)**.
* **Stealth Interactive UI Actions:** * Incorrect choice arrays execute an immediate scale-down shrink operation and drop cleanly from the viewport.
  * Correct choices highlight instantly in high-visibility neon crimson, locking out subsequent clicks.
  * Correct selections instantly trigger a contextual code breakdown showcasing the target sentence template.
* **Live Clearance Analytics:** Complete the 10-node evaluation array to decrypt a real-time progress-ring scorecard highlighting first-attempt accuracy metrics and active mastery rankings (*Core Archon*, *Cyber Operative*, etc.).

---

## 🛠️ System Tech Stack

* **Backend Matrix:** Python, Django
* **Document Extraction Engine:** `pypdf` (Isolated local filesystem decoding)
* **Frontend Layer:** Vanilla HTML5, CSS3 Custom Properties (Variables), JavaScript (ES6 asynchronous transactions)
